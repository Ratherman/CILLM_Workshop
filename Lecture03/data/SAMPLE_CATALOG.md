# 延伸練習素材

所有內容皆為虛構教學資料，不可作為真實營運依據。

## Text

- `weather_disruption_notice.txt`：抽取班號、延誤、部門、時間與後續動作。
- `maintenance_shift_handover.txt`：辨識未完成事項與航空器放行狀態。
- `passenger_feedback.txt`：做情緒、優缺點與改善建議整理。
- `security_incident_report.txt`：整理資安事件時間軸與待辦事項。
- `mixed_language_cabin_log.txt`：測試中英混合內容與跨部門事件分類。

## Images

- `gate_delay_display.png`：讀取班號、登機門、目的地與延誤時間。
- `fictional_baggage_tag.png`：辨識行李路線、班號、標籤與易碎物提示。
- `ramp_safety_inspection.png`：找出機坪安全風險並形成檢查清單。
- `mock_boarding_pass.png`：辨識班號、登機門與座位。

## Audio

- `weather_delay_announcement.wav`：抽取延誤原因、班號、登機門與服務。
- `maintenance_handover.wav`：整理工單、故障狀況與未完成工作。
- `passenger_service_dialogue.wav`：區分旅客需求與客服回覆。
- `bilingual_boarding_call.wav`：測試中英雙語轉錄。

## 建議提問

1. 將資料標準化後，比較不同格式是否提到相同班號。
2. 請 Agent 列出內容中的部門、時間、風險與待辦事項。
3. 對照旅客服務 Resource，判斷案例是否達到餐飲券門檻。
4. 故意換錯檔案或提出資料中沒有答案的問題，觀察模型是否誠實說明限制。
