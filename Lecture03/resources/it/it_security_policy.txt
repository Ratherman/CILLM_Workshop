資訊安全規範（虛構教學資料）
1. 密碼至少每 90 天更新。
2. API key 不得寫入原始碼。
3. 內部資料不得上傳公開 AI 服務。
4. 管理帳號必須啟用多因素驗證。
5. 可疑郵件應回報資安窗口。
6. 個人裝置不得存放未加密旅客資料。
7. 權限依最小必要原則核發。
8. 離職帳號應於當日停用。
9. 系統日誌至少保存 180 天。
10. 資安事件一小時內完成初報。
11. API key 應存放於環境變數或核准的秘密管理服務，不得提交至 Git。
12. 發現 API key 外洩時應立即撤銷、重新產生並檢查使用紀錄。
13. 密碼不得與其他外部服務共用，也不得透過郵件或聊天工具傳送。
14. 連續登入失敗達門檻時，系統應暫時鎖定帳號並留下稽核紀錄。
15. 測試資料仍應遵循最小揭露原則，不得使用真實旅客個資。
